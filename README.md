# MyIA — RoleConfig AI

MyIA est une plateforme d’assistant LLM configurable par métier et par contexte d’usage.

## Objectif

Permettre à une organisation de configurer, tester, gouverner et améliorer des assistants IA sans reconstruire un assistant dédié par métier.

## Contenu de ce dépôt

- `docs/cahier-des-charges-roleconfig-ai.md` : cahier des charges produit complet.
- `docs/mvp-implementation-plan.md` : plan d’implémentation MVP orienté produit/technique.

## Vision MVP

- 3 profils initiaux (PO, Comptable, Chercheur)
- Sélection de profil + saisie de prompt
- Réponse générée selon configuration déclarative
- Affichage des règles actives
- Logs d’exécution
- Feedback simple
- Campagne de tests basique
- Dashboard minimal
